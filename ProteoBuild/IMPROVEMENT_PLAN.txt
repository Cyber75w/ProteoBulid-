# ProteoBuild UI/UX Improvement Plan

## Phase 1: Foundation & CSS Reorganization (~8h)

### 1.1 Unminify & Restructure CSS
Split single-line CSS into logical sections with clear comments:
- Tokens & Custom Properties
- Reset & Base
- Layout (sidebar, main, grids)
- Components (buttons, cards, panels, inputs)
- View-specific styles (home, amino, secondary, folding, stability)
- Utilities (spacing, typography, visibility)
- Media Queries (breakpoints)

### 1.2 Design Token Overhaul
Add semantic aliases:
```
--bg, --surface, --surface-hover, --surface-pressed
--border, --border-strong, --border-focus
--text, --text-muted, --text-inverse
--focus-ring, --shadow-sm, --shadow-md, --shadow-lg
--radius-sm, --radius-md, --radius-lg
--transition-fast, --transition-normal, --transition-slow
```
Deprecate direct color usage in components.

### 1.3 Dark Mode Support
- `[data-theme="dark"]` overrides + `@media (prefers-color-scheme: dark)`
- Theme toggle button in sidebar (top-right, icon: sun/moon)
- Persist preference in `localStorage` ('theme': 'light'|'dark'|'system')
- Sync on load, watch for system changes

### 1.4 Focus Management
- Visible `:focus-visible` rings on ALL interactive elements (3px solid var(--focus-ring), offset 2px)
- Skip link at top of `<body>`: "Skip to main content"
- ARIA labels on icon-only buttons (nav, reset, fullscreen, etc.)
- Logical tab order audit

### 1.5 Reduced Motion
`@media (prefers-reduced-motion: reduce)` disables:
- Hero art float/rotate animation
- Three.js auto-rotate (`controls.autoRotate = false`)
- All `transition` and `animation` durations → 0.01ms
- Progress bar width transition
- Stability meter score animation

### 1.6 CSS Custom Properties for Dynamic Values
- Stability meter: `--score-deg` (conic-gradient angle) — animate via `transition: --score-deg 0.6s ease-out`
- Update via `element.style.setProperty('--score-deg', \`${score * 3.6}deg\`)`

## Phase 2: Visual Polish & Micro-interactions (~7.5h)

### 2.1 Button/Tile Press States
- `:active { transform: scale(0.98) }` on amino tiles, nav items, module cards
- Primary button: CSS ripple (pseudo-element, `opacity: 0 → 0.3`, `transform: scale(0 → 2)`)

### 2.2 Loading Skeletons
- Amino grid: 20 shimmer placeholders (`.skeleton` with `background: linear-gradient(90deg, var(--surface) 25%, var(--surface-hover) 50%, var(--surface) 75%)`, `animation: shimmer 1.5s infinite`)
- 3D viewer: Static SVG illustration + spinner (`.viewer-loading` enhanced)
- Sequence output: Gray rounded chips (`min-width: 28px`)

### 2.3 Hero Art Animation
- Protein shapes: `animation: float 3s ease-in-out infinite, slow-rotate 20s linear infinite`
- Respect `prefers-reduced-motion` → `animation: none`

### 2.4 Stability Meter Animation
- `--score-deg` transition (0.6s ease-out)
- Counter: `requestAnimationFrame` count-up from previous value
- Label/copy cross-fade (opacity transition)

### 2.5 Sequence Chip Tooltips
- CSS-only: `.residue:hover::after, .residue:focus::after` with `attr(data-tooltip)`
- Shows full name + group (e.g., "Alanine — Nonpolar")

### 2.6 Progress Persistence
- `localStorage.setItem('proteobuild-completed', JSON.stringify([...completed]))`
- On load: restore `completed` Set, update nav checkmarks (`.nav-check { opacity: 1 }`)
- Progress bar width from `completed.size * 25%`

## Phase 3: Component Upgrades (~15.5h)

### 3.1 Sidebar Enhancements
- Collapse toggle (chevron button) → 64px icon-only rail
- Mobile (<760px): Off-canvas drawer, hamburger in topbar, swipe/backdrop to close
- Module completion badges persist in collapsed state

### 3.2 Amino Acid Grid Upgrades
- Search/filter input (debounced 150ms) above grid
- Group badges with counts: "Nonpolar (8)", "Polar (7)", "Charged (5)"
- Keyboard: Arrow keys navigate, Enter/Space adds, Escape clears filter
- Virtual scroll if items > 20 (IntersectionObserver)

### 3.3 3D Viewer Improvements
- Static SVG fallback illustration (inline in HTML) when Three.js fails
- Quality toggle: Low (40 beads), Medium (82), High (160) — re-renders tube
- Screenshot button: `canvas.toBlob()` → download PNG
- Fullscreen toggle: `requestFullscreen()` on viewer container

### 3.4 Stability Lab Presets
- Preset buttons: "Physiological", "Heat Shock (42°C)", "Extreme Acidic (pH 2)", "Extreme Basic (pH 12)", "High Salt (2M)"
- Undo/redo stack (last 10 states, stored in array)
- Export: `JSON.stringify({temp, pH, salt, score, timestamp})` → download .json

### 3.5 Secondary Structure Animations
- Hydrogen bonds: Staggered `animation: fade-in 0.4s ease forwards` with `--delay` custom property
- Parallel/antiparallel strand toggle (new button in structure-switch)
- Subtle Ramachandran plot reference (corner SVG, click to enlarge)

## Phase 4: UX Flow & Content (~9.5h)

### 4.1 Onboarding Coach Marks
- First visit detection: `!localStorage.getItem('proteobuild-onboarded')`
- 3-step tour (driver.js-style, CSS-only):
  1. Sidebar nav → "Switch modules here"
  2. Amino grid → "Click to build sequence"
  3. 3D viewer → "Drag to rotate, scroll to zoom"
- Dismissible, "Don't show again" checkbox → sets flag

### 4.2 Module Completion UI
- "Mark complete" button per module (footer of each lesson-view)
- Confetti: CSS keyframes burst (12 particles, random angles, `transform: translate() scale()`, `opacity: 1→0`)
- Progress updates instantly, nav checkmark appears

### 4.3 Navigation Enhancements
- Breadcrumb clickable: "BIOTECHNOLOGY / UNIT III" → `#view-home`
- Deep-link: `window.location.hash` → `navigate(view)` on load
- `history.pushState()` on nav → back/forward works
- URL updates without reload

### 4.4 Empty States
- Sequence: Illustrated drop zone (SVG), "Click amino acids to start"
- 3D viewer: Static illustration + "Retry loading 3D model" button
- Structure: Placeholder with "Select a structure above"

### 4.5 Error Boundaries
- Three.js try/catch → show static SVG + "Retry" button (re-inits)
- Offline detection: `navigator.onLine` + `window.addEventListener('online/offline')` → top banner
- Graceful degradation: All content readable without JS
